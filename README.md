# ✿ Memory Match ✿

A pastel memory card game where matched pairs poof away and hard mode fights back. Vibe coded and designed for mobile first.

🌸 **[Play it live](https://soumyag777.github.io/Memory-Match-Game/)**

## How to play
Flip two cards at a time to find matching emoji pairs. Clear the whole board in as few moves as you can.

## Levels
- 🌷 **Easy:** 6 pairs
- 🍓 **Medium:** 8 pairs
- 🌀 **Hard:** 10 pairs, and every wrong guess reshuffles the cards still on the board, so you can't rely on memory alone

## Features
- Bouncy 3D card flips
- Matched pairs pop, then disappear, so the board clears as you play
- Wrong guesses give a gentle shake instead of a harsh error
- Timer, move counter, and pairs tracker
- Emoji confetti when you win
- Saves your best score for each level

## Built with
HTML, CSS, and vanilla JavaScript in one file, so there are no frameworks or installs. The font is [Fredoka](https://fonts.google.com/specimen/Fredoka). It's hosted on GitHub Pages.

## Design notes
I wanted every interaction to give friendly feedback: a shake for a miss, a pop for a match, and confetti for a win. Making matched cards disappear keeps the board focused on what's left. Hard mode's reshuffle shifts the challenge from memory to quick recall, which keeps the game fresh for repeat players.
